# 插件架构

VoxChat 使用 Node.js ESM 和内置 SQLite，运行在 DSH 插件进程中。管理设置页由 React 组件组成，构建为 DSH 客户端扩展；手机端不在此仓库中。

## 模块

| 路径 | 职责 |
| --- | --- |
| `src/index.js` | 组装插件服务，注册路由并负责卸载清理 |
| `src/contracts.js` | 设备协议常量和资源限制 |
| `src/config.js` | 配置校验、模型继承和密钥脱敏 |
| `src/store.js` | 初始化数据结构，存储配置、音色、设备、授权、配对及请求去重信息 |
| `src/dsh.js` | 原生工作区、会话、可见事件、发送消息和模型适配 |
| `src/voice.js` | ASR、播报总结与 TTS 请求 |
| `src/service.js` | 设备授权、管理命令和语音流程编排 |
| `src/http.js` | 设备 HTTP 接口、输入校验和 NDJSON 输出 |
| `src/admin.js`、`src/remote.js` | 已认证 DSH owner Remote 管理入口 |
| `src/connection.js`、`src/tunnel.js` | 手动入口、Cloudflare Quick Tunnel 和进程生命周期 |
| `client/model.js` | 设置草稿与批量保存命令 |
| `client/pairing.js` | 扫码链接与本地二维码编码 |
| `client/panel.js`、`client/panel.css` | DSH 管理设置页 |
| `scripts/` | 客户端构建与 JavaScript 语法检查 |
| `tests/` | 单元、HTTP 和真实 DSH 宿主集成测试 |

`npm run build` 将管理页、Remote 描述及二维码库打包为 `dist/client.js`。构建产物、安装包、数据库、缓存和本机备份不提交到 Git。

## 语音流程

```text
客户端录音 → HTTP → ASR → DSH 会话 → 播报总结 → TTS → NDJSON 音频流
```

转写成为 DSH 的用户输入，DSH 自身保存完整会话和原文。总结通过独立模型请求生成，不写回会话。ASR、TTS 和独立总结使用 OpenAI 兼容接口；继承总结模型时使用当前会话的 DSH 模型适配器。

每轮开始时固定设备授权、工作区、会话、模型和音色。中途切换设备选择只影响下一轮。回复仅送给发起设备，不向其他设备广播。

## 数据结构

| 表 | 内容 |
| --- | --- |
| `settings` | 插件级模型配置、手动地址和管理配置版本 |
| `devices` | 设备身份、凭证摘要、配对码摘要、当前工作区、音色和设备模型配置 |
| `device_workspaces` | 设备与工作区授权，以及该关联下选择的会话 |
| `workspaces` | 已授权工作区的 ID 登记 |
| `voices` | 音色显示名称和 TTS 服务音色 ID |
| `turns` | 请求 ID、归属会话与执行状态，防止重复执行 |
| `connection` | 最后一次生效的连接地址 |

工作区和会话由 DSH 管理，插件只引用已有记录。先创建设备，再通过 `bindDevice` 授权工作区，首次授权自动登记。解除关联不会撤销设备凭证；设备移除或连接地址变化会使凭证失效。

客户端选择音色、工作区和会话属于运行状态，不递增管理员配置版本。管理保存不提交这些选择，避免覆盖设备刚作出的操作。管理修改使用 `revision` 乐观锁和 SQLite 事务，失败整体回滚。

数据库在首次启动时直接建立当前结构；后续启动读取已保存的配置和设备状态。本版本面向全新安装，不包含开发旧版的数据转换或兼容处理。

## 边界与生命周期

- 模型配置按整项能力采用“设备 → 插件 → 当前会话（仅总结）”顺序，不混用不同服务的密钥。
- 所有管理操作通过 DSH owner Remote；公网设备接口仅接受设备凭证，不提供配置写入能力。
- 配对码为 6 位字母数字、一次使用、5 分钟有效；只在创建设备或手动刷新时签发。二维码只包含实际地址和配对码。
- 同一设备或会话只运行一轮请求。断线、取消、授权撤销、地址变化或卸载会中止受影响请求。
- 请求 ID 持久化去重，重启后未完成请求标记为中断，不自动重发或重放音频。
- 公网隧道仅转发设备路由，使用单独的本机临时端口，不转发 DSH 管理页。详见 [连接说明](connection.md)。

DSH `0.2.1-rc.2` 固定按设置分区 ID 渲染侧栏图标。插件只为“语音交互”入口设置麦克风样式，卸载时清理观察器、标记和样式。

## 验证

测试覆盖配置继承、密钥隔离、事务与重启、设备和工作区隔离、并发与取消、HTTP 流、二维码独立解码及管理页操作。设置 `DSH_TEST_PACKAGE` 后启用真实宿主集成测试，使用临时 profile 和本地模型服务。
